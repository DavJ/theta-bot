## How to Read This Registry

Each entry uses the following classification vocabulary:

| Status Code | Meaning |
|---|---|
| VALID | Methodology sound; evaluation path trusted |
| VALID_BUT_LIMITED | Sound method but scope, data, or horizon is narrow |
| INVALID_EVAL | Evaluator did not test the intended model (bug, fallback, wrong code path) |
| NOT_COMPARABLE | Cannot be directly compared to other experiments |
| SYNTHETIC_ONLY | Result only on synthetic/mock data; no real-market test |
| REAL_DATA_WEAK | Tested on real data; result insignificant or negative |
| DEAD_END | No evidence of edge; approach structurally unfit |
| UNCLEAR_NEEDS_RERUN | Evaluator path uncertain or test blocked by infrastructure |

Cost realism: NONE | PARTIAL | REALISTIC | UNKNOWN
